# Arkanoid-like-web-game

CSS/<br>
style.css - стиль страницы и игрового поля<br>

JS/<br>
main.js - запускает игру с указанным шрифтом, при его наличии<br>
assets.js - графическое описание игровых объектов<br>
audio.js - описание звуков и их создание<br>
collision.js - расчёт коллизии объектов при столкновении<br>
config.js - настройки игры<br>
effects.js - создание визуальных эффектов, при взаимодействии объектов на сцене<br>
input.js - управление в игре, ввод клавиш<br>
levels.js - описание уровней и их загрузка<br>
physics.js - физика объектов при взаимодействии<br>
prefabs.js - основные игровые префабы<br>
render.js - рендер графики на экране, отрисовка кадров, создание игрового поля<br>
ui.js - описание элементов интерфейса, из создание и изменение<br>
game.js - загрузка игры, игровой цикл<br>

Index.html - корень страницы, запуск игры<br>
