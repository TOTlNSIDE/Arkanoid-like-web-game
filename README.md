# Arkanoid-like-web-game

CSS/
style.css - стиль страницы и игрового поля

JS/
main.js - запускает игру
assets.js - графическое описание игровых объектов
audio.js - описание звуков и их создание
collision.js - расчёт коллизии объектов при столкновении
config.js - настройки игры
effects.js - создание визуальных эффектов, при взаимодействии объектов на сцене
input.js - управление в игре, ввод клавиш
levels.js - описание уровней и их загрузка
physics.js - физика объектов при взаимодействии
prefabs.js - основные игровые префабы
render.js - рендер графики на экране, отрисовка кадров, создание игрового поля
ui.js - описание элементов интерфейса, из создание и изменение
game.js - загрузка игры, игровой цикл

Index.html - корень страницы, запуск игры
